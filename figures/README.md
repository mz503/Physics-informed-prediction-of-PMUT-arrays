# Figures

- `main/` contains the available PMUT prediction plots.
- `model_parameters/` contains the available parameter-trajectory plots.
- `legacy_duplicates/` preserves duplicate copies from multiple original
  output locations; these are archival copies, not separate runs.

Complete plotting scripts, panel source data, captions, and run identifiers
were not included for the pre-existing exports. `scripts/08_progressive_images.py`
regenerates the progressive prediction plots from the cached predictions.
