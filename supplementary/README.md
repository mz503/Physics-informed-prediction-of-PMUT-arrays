# Supplementary materials

- `explorer/` contains the available interactive progressive and regime HTML
  exports and their associated metric CSVs.
- `model_explanations/` contains the supplied model explanation documents and
  HTML exports.
- `FHWM.ipynb` is the supplied exploratory notebook.
- `validation_artifacts/` is reserved for extended validation outputs. The
  former `scratch/` test images and parameter-table helper were removed before
  they could be relocated; they are not available in this folder.
