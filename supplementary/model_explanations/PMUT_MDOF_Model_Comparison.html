🔬 Model Architectures & Governing Equations
Analytical MDOF
Classical Physics

Direct experimental frequency response decomposition into a multi-mode mechanical harmonic oscillator superposition model.

$$H(\omega) = \sum_{i=1}^K \frac{A_i \omega_{0,i}^2}{(\omega_{0,i}^2 - \omega^2) + j \left(\frac{\omega_{0,i}\omega}{Q_i}\right)} + A_{\text{bg}}$$
  • Direct fitting per single device spectrum
  • Identifies exact resonant frequencies ($f_{0,i}$) & $Q_i$
  • Cannot generalize across unseen array sizes ($N$)
MDOF-PINN
Baseline PINN

Neural network mapping PMUT array size $N \to [A_{\text{bg}}, A_i, f_{0,i}, Q_i]$, feeding a differentiable modal transfer layer.

$$\mathcal{L} = \mathcal{L}_{\text{MSE}} = \frac{1}{M} \sum_{i=1}^M (A_{\text{pred},i} - A_{\text{exp},i})^2$$
  • Maps array size $N$ directly to MDOF parameters
  • Preserves multi-mode peak transfer function shape
  • No physical parameter constraints ($m, c, k$)
PINN-Informed-Loss
System ID

Predicts fundamental physical parameters $\theta_N = [m_N, c_N, k_N, Q_N, A_N]$ through a Differentiable Oscillator Layer with Informed Loss.

$$\mathcal{L} = \lambda_d \mathcal{L}_{\text{data}} + \lambda_p \mathcal{L}_{\text{physics}} + \lambda_s \mathcal{L}_{\text{smooth}}$$
  • Enforces physical positivity: $m_N, c_N, k_N, Q_N > 0$
  • Physical consistency: $Q_N = \frac{\sqrt{m_N k_N}}{c_N}$
  • Smoothness regularizer across array sizes
RF-MDOF-PINN
Hybrid Ensemble

Combines MDOF-PINN multi-mode mechanical physics backbone with Random Forest residual error interpolation.

$$y_{\text{ens}}(f, N) = y_{\text{mdof\_pinn}}(f, N) + \text{RF}_{\text{res}}(f, N)$$
  • Guarantees physical resonance bounds & Q-factors
  • Fits non-linear empirical residual variations
  • Prevents cross-regime extrapolation $R^2$ crash ($R^2=0.534$ on P12) while reaching $R^2 > 0.999$
