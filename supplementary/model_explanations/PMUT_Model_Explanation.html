PMUT modeling overview

Physics-informed and reduced-order models for PMUT response prediction

This report summarizes how the project fits and compares four complementary models for PMUT frequency-response data: the single-mode SDOF physics model, the PINN surrogate, the multi-branch Butterworth–Van Dyke (BVD) equivalent circuit, and the multi-mode mechanical MDOF model. The goal is to learn the physical parameters behind resonance and to predict full spectral curves as the PMUT array size N changes.

Project context

The data consists of measured PMUT amplitude spectra over frequency, indexed by array size N. The problem is to map the array size to a frequency response model and to recover interpretable physical parameters such as resonance frequency, stiffness, damping, background offset, and modal gain. In the repository, this is done through a combination of direct fitting, physics-informed network training, and circuit/mode-based parameter extraction.

  • Direct-fit SDOF model is used as the “ground truth” reference for each PMUT spectrum.
  • PINN learns the mapping from N to SDOF parameters across the full array range.
  • BVD fits an electrical equivalent circuit to the admittance magnitude.
  • MDOF fits a superposition of several mechanical resonators to the response.

1) SDOF physics model

The single-degree-of-freedom (SDOF) model treats a PMUT as a forced, damped oscillator. The code fixes the effective mass to m = 0.38 and estimates the parameters for each PMUT: the force coefficient α, resonant frequency f0, quality factor Q, gain G, and background offset A_bg.

\[ \omega = 2\pi f, \quad \omega_0 = 2\pi f_0 \] \[ k = m\omega_0^2, \quad c = \frac{m\omega_0}{Q} \] \[ |X(\omega)| = \frac{\alpha V}{\sqrt{(k - m\omega^2)^2 + (c\omega)^2 + 10^{-12}}} \] \[ A_{\text{pred}}(f) = G|X(\omega)| + A_{bg} \]

Physical meaning of the parameters

  • α: force-to-displacement coupling coefficient.
  • f0: resonant frequency, in MHz.
  • Q: quality factor, describing damping and selectivity.
  • k: effective stiffness, computed from the mass and resonant frequency.
  • c: effective damping coefficient, computed from m, ω0, and Q.
  • G: gain or scaling factor from displacement to measured amplitude.
  • A_bg: baseline offset or background response.

How the SDOF parameters were extracted

For each measured PMUT spectrum, the function fit_sdof_directly initializes a PyTorch optimization with a small set of learnable parameters: [alpha, f0, Q, A_bg]. The optimization minimizes a variance-normalized MSE between the model output and the measured amplitude spectrum, with a small regularization on unrealistic Q values.

\[ \text{loss} = \frac{\mathrm{MSE}(A_{\text{pred}}, A_{\text{true}})}{\mathrm{Var}(A_{\text{true}})} + 10^{-3}\,q_{\text{reg}} \] \[ q_{\text{reg}} = \mathrm{ReLU}(0.1 - Q)^2 + \mathrm{ReLU}(Q - 500)^2 \]

This direct fit produces the “true” SDOF parameter set used as a reference against which the PINN estimates are compared. It is stored in the physics comparison table and the associated HTML outputs.

2) PINN for array-size-to-physics mapping

The PINN does not fit one PMUT at a time. Instead, it learns a function from array size N to the SDOF parameter vector [alpha_N, f0_N, Q_N, G_N, A_bg]. The neural network input is a scalar N value; the output is a physics-parameter set for the PMUT with that array size.

\[ N \;\mapsto\; [\alpha_N, f_{0,N}, Q_N, G_N, A_{bg}] \] \[ \omega_{0,N} = 2\pi f_{0,N}, \quad k_N = m\omega_{0,N}^2 \] \[ c_N = \frac{m\omega_{0,N}}{Q_N} \] \[ A_{\text{pred}}(f, N) = G_N |X(\omega, N)| + A_{bg} \] \[ |X(\omega, N)| = \frac{\alpha_N V}{\sqrt{(k_N - m\omega^2)^2 + (c_N\omega)^2 + 10^{-12}}} \]

Network architecture

  • Input: scalar PMUT array size N.
  • Hidden layers: two SiLU layers with dimension 32.
  • Output: five constrained parameters for the single-mode model.
  • Positivity constraints: Softplus applied to alpha, f0, Q, and G.
  • Mass is fixed to m = 0.38 and is treated as a physical constant.

How the PINN was trained

In the code, fit_pinn assembles frequency-response pairs from all PMUTs, stacks the N, frequency, and amplitude arrays, and trains the model with Adam optimizer. The loss is the mean squared error between predicted and measured amplitudes plus a mild Q-penalty.

\[ \text{loss} = \mathrm{MSE}(A_{\text{pred}}, A_{\text{true}}) + 10^{-4}\,q_{\text{reg}} \] \[ q_{\text{reg}} = \mathrm{mean}\left(\mathrm{ReLU}(0.5 - Q)^2 + \mathrm{ReLU}(Q - 100)^2\right) \]

The output parameters are explicitly constrained to be physically meaningful: alpha, f0, Q, and G are positive; the background offset is allowed to be unbounded. This makes the learned model interpretable and keeps it consistent with the theoretical SDOF oscillator form.

3) BVD equivalent circuit model

The Butterworth–Van Dyke (BVD) model explains the PMUT as an electrical equivalent network with a static capacitance C0 and a set of resonant motional branches. Each branch is represented by a motional resistance, inductance, and capacitance.

\[ Y_{\text{static}}(\omega) = j\omega C_0 \] \[ Z_{m,i}(\omega) = R_{m,i} + j\left(\omega L_{m,i} - \frac{1}{\omega C_{m,i}}\right) \] \[ Y_{m,i}(\omega) = \frac{1}{Z_{m,i}(\omega)} \] \[ |Y_{\text{pred}}(\omega)| = \left|Y_{\text{static}}(\omega) + \sum_i Y_{m,i}(\omega)\right| + A_{bg} \]

BVD parameters

  • C0: static capacitance.
  • A_bg: background admittance offset.
  • f0,i: resonance frequency of branch i.
  • Q_i: quality factor of branch i.
  • R_m,i, L_m,i, C_m,i: branch motional electrical parameters.

How BVD was trained

The function fit_bvd_pmut converts the measured frequency points to angular frequency, initializes the branch resonances from spectral peaks, and optimizes the BVD parameters with Adam in double precision. The loss is a variance-normalized MSE between the predicted admittance magnitude and the measured magnitude. The code uses Softplus transformations to enforce positivity for the physical parameters.

\[ \text{loss} = \frac{\mathrm{MSE}(|Y_{\text{pred}}|, |Y_{\text{true}}|)}{\mathrm{Var}(|Y_{\text{true}}|)} \]

This model is useful because it describes the PMUT as an electrical resonator with physically meaningful values that can be compared to the mechanical oscillation model.

4) MDOF mechanical superposition model

The multi-mode mechanical superposition model assumes the response is the sum of several uncoupled resonant modes. Each mode contributes a transfer function H_i(ω), and the total response is the amplitude of the sum.

\[ A_{bg,\text{init}} = \min(y_{\text{true}}), \quad y_{\text{centered}} = y_{\text{true}} - A_{bg,\text{init}} \] \[ S = \max(y_{\text{centered}}), \quad y_{\text{norm}} = \frac{y_{\text{centered}}}{S} \] \[ H_i(\omega) = \frac{\alpha_i V}{(k_i - m_i\omega^2) + j(c_i\omega)} \] \[ y_{\text{pred,norm}}(\omega) = \left|\sum_i H_i(\omega)\right|, \quad y_{\text{pred,actual}}(\omega) = y_{\text{pred,norm}}(\omega)S + A_{bg} \]

MDOF parameters

  • f0,i: modal resonance frequencies.
  • Q_i: modal quality factors.
  • k_i: modal stiffness.
  • c_i: modal damping.
  • αi: modal excitation coefficient.
  • A_bg: baseline offset.
  • S: overall scale factor used during normalization.

How MDOF was trained

In fit_mdof_pmut, the measured amplitude is first normalized by subtracting the minimum and dividing by the maximum range. The model then initializes modal frequencies from magnitude peaks in the spectrum and optimizes each mode’s frequency, damping, and mode gain. The total response is the magnitude of the sum of modal responses, with a modest penalty on non-physical Q values.

\[ \text{total\_loss} = \mathrm{MSE}\left(\left|\sum_i H_i(\omega)\right|, y_{\text{norm}}\right) + 10^{-3}\,q_{\text{penalty}} \]

This gives a physically interpretable multi-resonance description that is more flexible than the single-mode SDOF model while remaining tied to the mechanics of the PMUT.

5) Training workflow and parameter extraction pipeline

The project follows a consistent recipe for all the models:

  1. Load each PMUT spectrum and sort it by frequency.
  2. Extract a direct-fit SDOF reference using fit_sdof_directly.
  3. Train or fit the physics-informed or reduced-order model to the spectral data.
  4. Extract the physical parameters from the model and compare them to the direct-fit reference.
  5. Save CSV and HTML comparison tables for inspection and plotting.

Outputs produced by the project

  • PINN physics comparison: output tables and HTML comparison of true vs. estimated SDOF parameters.
  • BVD comparison: extracted C0, A_bg, per-mode f0, Q, R_m, L_m, C_m.
  • MDOF comparison: extracted mode frequencies, Qs, stiffnesses, dampings, gains, and baseline.
  • Progressive and regime-aware training outputs: multi-model performance summaries over PMUT index.

6) Results and interpretation

Across the PMUT dataset, the fitted models capture the resonance structure well and show a clear relationship between the array size and the mechanics. The direct-fit SDOF model provides a physically grounded reference, while the PINN learns a smooth mapping from N to the fitted physics parameters across the array. The BVD and MDOF models provide alternative views of the same response: an electrical circuit perspective and a mechanical multi-modal perspective.

Model Primary idea Strength Typical interpretation
SDOF Single damped oscillator Simple and physically interpretable Baseline resonance, damping, stiffness and gain
PINN Neural mapping N → SDOF parameters Predicts across array sizes without per-device fitting Fast surrogate for physics-conditioned PMUT response
BVD Equivalent electrical circuit Captures electrical admittance behavior and branch resonances C0, branch resonances, motional resistance and inductance
MDOF Sum of resonant modes More flexible than SDOF; models multiple modal peaks Multi-mode mechanics, damping and mode strengths

In the project’s comparison outputs, the fitted values from the two physics-informed models are evaluated against the direct-fit SDOF results. The plots and tables show that the PINN estimates of f0, Q, k, and c follow the same trends as the direct-fit values, while the multi-mode forms capture additional spectral detail when multiple resonant branches are present. The progressive-training HTML reports indicate that the single-mode and multi-mode predictions achieve low to moderate MAE and track the dominant resonance trend across PMUT sizes, with the best-performing models generally reducing error substantially compared with a naive baseline.

7) Conclusion

The project combines a physically grounded SDOF model with data-driven learning and reduced-order circuit/mode descriptions to explain and predict PMUT frequency responses. The SDOF equations give the mechanistic interpretation, the PINN provides a fast mapping across array sizes, and the BVD/MDOF models offer complementary views of the same underlying dynamics. Together, they produce a consistent picture: the PMUT response is governed by a resonant mechanical system whose stiffness, damping, resonance frequency, and background response change systematically with array size and can be learned and modeled.
