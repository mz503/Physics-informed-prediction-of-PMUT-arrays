# Results

- `predictions/`: progressive/regime prediction caches; `archive/` preserves
  duplicate prediction caches from the original `Cache Data/`.
- `metrics/`: progressive/regime exported metric tables.
- `direct_fits/`: direct physical fit comparison tables and HTML.
- `baselines/` and `validation/`: reserved for future exports; no corresponding
  result files were present.

The caches do not retain full floating-point precision. Run identifiers and
full metric provenance were not included with the source files.
