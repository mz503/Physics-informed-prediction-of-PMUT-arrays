# Data

- `raw/` contains the two available source workbooks and the supplied zip
  archive (preserved as provided; its contents have not been independently
  classified).
- `processed/pmuts_all.csv` is the unified, sorted, averaged-spectrum export.
- `processed/archive/` preserves the duplicate processed CSV from the old
  `Cache Data/` folder.

The files do not include the full repeat-sweep exports, measurement
identifiers, or acquisition settings. See `docs/data_dictionary.md`.
